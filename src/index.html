Quatre sections simples pour lire les principaux écarts.

Les plateformes

Les plateformes ne se distinguent pas seulement par leur popularité. Elles se différencient aussi par le sommeil moyen, la santé mentale, les conflits et la part d'impact académique négatif.

Le temps d'utilisation

Quand le temps d'utilisation augmente, le sommeil et la santé mentale n'évoluent pas toujours au même rythme. Cette vue permet de comparer clairement les deux tendances.

Les conflits

Les conflits sont présentés ici comme le résultat d'une combinaison entre le temps passé sur les réseaux et le niveau d'addiction. Les zones plus intenses font ressortir les situations les plus sensibles.

L'impact académique

L'effet sur les études se lit ici sous deux angles complémentaires : selon l'usage et le sommeil, puis selon le score d'addiction. Les trois vues sont regroupées pour rendre la lecture plus continue.
