# Social Media Usage

Ce projet présente une visualisation interactive sur l'impact des médias sociaux sur le bien-être des étudiants.

## Accessibilité

L'application inclut un panneau d'accessibilité accessible via le bouton situé en bas à droite de l'écran.

### Options disponibles

- `Contraste élevé` : augmente le contraste global de l'interface pour améliorer la lisibilité.
- `Motifs graphiques` : ajoute des motifs visuels sur certaines séries de graphiques et leurs légendes pour éviter une lecture basée uniquement sur la couleur.
- `Réduire les animations` : réduit fortement les transitions et animations de l'interface.
- `Taille du texte` : permet de choisir entre `Normal`, `Grand` et `Très grand`.
- `Indicateurs de focus visibles` : renforce la visibilité du focus clavier sur les éléments interactifs.

Les préférences sont sauvegardées localement dans le navigateur.

### Navigation clavier

- `Alt + H` : affiche l'aide clavier.
- `Alt + S` : saute au contenu principal.
- `Alt + 0` : va à l'accueil.
- `Alt + 1` à `Alt + 4` : navigue directement vers les sections.
- `Tab` : navigue entre les éléments interactifs et les graphiques.
- `↑ ↓ ← →` : explore les données dans les graphiques compatibles.
- `Entrée` / `Espace` : active ou sélectionne l'élément ciblé.

### Aides supplémentaires

- Les graphiques principaux disposent de descriptions accessibles.
- Les tooltips peuvent s'afficher au focus clavier.
- Les valeurs explorées au clavier peuvent être annoncées par un lecteur d'écran.
